# DCF Valuation Model

## Overview

This project develops a Discounted Cash Flow (DCF) valuation model using Python.

The model forecasts revenue, EBITDA, EBIT, NOPAT and free cash flow before calculating enterprise value and implied equity value.

## Key Features

- Revenue forecasting
- EBITDA and EBIT calculation
- NOPAT calculation
- Free cash flow forecasting
- WACC-based discounting
- Terminal value calculation
- Enterprise value calculation
- Equity value calculation
- Implied value per share
- WACC and terminal growth sensitivity analysis

## Financial Concepts

The project applies:

- Discounted Cash Flow valuation
- WACC
- CAPM
- Terminal growth
- Enterprise value
- Equity value
- Free cash flow

## Technologies

- Python
- Pandas
- NumPy

## Purpose

The project was developed to strengthen practical financial modelling and valuation skills and demonstrate the application of Python to financial analysis.
